## Paradise Lagoon 🌴🏨
Welcome to Paradise Lagoon – your go-to online platform for booking luxurious hotel rooms at our picturesque resort. This project showcases a responsive and interactive website built with HTML, CSS, and JavaScript, designed to enhance your online booking experience.

### Project Overview
Paradise Lagoon is designed to make the online booking process simple and efficient. Users can browse through different room types, view detailed information and images, and make reservations seamlessly.

### Key Features
🏨 Room Listings: Browse through a variety of room types, including Deluxe Suites, Family Rooms, and Luxury Penthouses.
📸 High-Quality Images: Each room listing includes high-quality images to give users a clear view of the accommodations.
💲 Pricing and Details: Detailed information on room prices, capacity, bed types, and views.
🖱️ Easy Booking: Simple and intuitive booking process with clear call-to-action buttons.
📱 Responsive Design: Fully responsive layout that works seamlessly on desktops, tablets, and mobile devices.
### Motivation
Creating Paradise Lagoon was inspired by the need to provide a user-friendly, visually appealing platform for booking hotel rooms. The project aims to simplify the booking process and provide all necessary information at the users' fingertips, enhancing their overall experience.

Usage
Home Page: Start at homePage.html to get an overview of the resort and navigate to different sections.
Room Listings: Navigate to Listings.html to view and book rooms. Click on any room image or title to see more details and make a reservation.
Contact Us: Use contact.html to get in touch with the resort for any inquiries or additional information.
Project Structure
index.html: The landing page with an overview of the resort.
Listings.html: The main page for room listings.
contact.html: Contact page for inquiries.
assets/: Contains images and other static assets.
styles/: Contains CSS files for styling the website.
scripts/: Contains JavaScript files for functionality.
